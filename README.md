# Crosshair KVA

Прицел поверх экрана для Windows с фиолетовым интерфейсом, конструктором и общим каталогом.

**Скачать программу:** готовый `CrosshairKVA.exe` находится в разделе **Releases** этого репозитория. Сайт проекта: https://kvacrosshair.online.

## Возможности

- Крест, точка, круг и Т-образный прицел; настройка цвета, размера, толщины, прозрачности и положения.
- Импорт PNG и анимированных GIF, несколько профилей и отдельная вкладка установленных прицелов.
- Конструктор с кистью, ластиком, заливкой, фигурами, отменой и экспортом прозрачного PNG.
- Импорт в конструктор сохраняет исходные пиксели и разрешение изображения.
- Общий каталог: просмотр и скачивание без регистрации, публикация и удаление своих прицелов после входа.
- KVA PRO: цвет ника, нейросетевое удаление фона и аниме-лайн с деталями лица, волос и одежды.
- Локальная обработка изображений; модели скачиваются отдельно при первом использовании.
- Автоматическая загрузка обновлений с проверкой подписи и установка после перезапуска.
- Компактный оверлей Win32: статичный прицел не перерисовывается в фоне и пропускает клики.

Базовые функции бесплатны. Тарифы PRO: 100 ₽ / 30 дней, 250 ₽ / 3 месяца, 500 ₽ / 6 месяцев, 900 ₽ / год. Автосписаний нет.

Оплата через ЮKassa на сайте или внутри приложения: войдите в тот же аккаунт и укажите email для чека. Подписка активируется после подтверждения платежа сервером. Чеки самозанятого оформляются вручную через «Мой налог».

## Запуск

Скачайте `CrosshairKVA.exe` из Releases и запустите его. Устанавливать Python для готовой программы не нужно.

- **F8** — включить или выключить прицел.
- **F9** — скрыть или показать настройки.

Для отображения поверх игры используйте оконный режим без рамки. Прицел расположен на основном экране. Приложение не внедряется в процесс игры.

Профили, копии изображений и модели сохраняются в `%LOCALAPPDATA%/CrosshairKVA`.

## Запуск из исходников

Нужны Windows и Python 3.12+:

```powershell
python -m pip install -r requirements.txt
python main.py
```

Для локального каталога:

```powershell
python catalog_server.py
```

## Сборка

```powershell
python -m pip install pyinstaller
python -m PyInstaller --onefile --windowed --name CrosshairKVA --icon assets/icon.ico --add-data "assets;assets" --distpath dist/release main.py
```

Закрытый ключ подписи выпусков и ключи платёжных сервисов в репозиторий не входят. Сборки из изменённых исходников используют встроенный адрес обновлений официального приложения; для собственного выпуска нужно настроить свой адрес и открытый ключ в `updater.py`.

## Проверки

```powershell
python -m unittest discover -s tests
```

## Нейросетевые модели

Удаление фона использует [anime-segmentation](https://github.com/SkyTNT/anime-segmentation); извлечение линий — улучшенную [Anime2Sketch](https://github.com/Mukosame/Anime2Sketch). Модели работают локально через ONNX Runtime. Лицензии сторонних моделей находятся в `assets/*-LICENSE.txt`.
