# Общая подписка KVA PRO + Kwyjibo VPN

С версии Crosshair KVA 0.10.0 и Kwyjibo VPN 1.4.0 оплата через ЮKassa включает оба продукта. Тарифы: 100 ₽ / 30 дней, 250 ₽ / 3 календарных месяца, 500 ₽ / 6 календарных месяцев, 900 ₽ / год. Срок добавляется к оставшемуся времени; автосписаний нет.

Логины и пароли отдельные. Пользователь получает одноразовый код на `/conection.html` после входа в KVA. Код действует 10 минут, хранится на сервере только как SHA256, новый код отменяет предыдущий. Он используется для входа в автоматически созданный VPN-профиль либо привязки своего существующего VPN-аккаунта/Telegram-бота. Совпадение ника не объединяет аккаунты.

С Kwyjibo VPN 1.4.2 привязка KVA необязательна: приложение и бот принимают оплату без KVA-регистрации. Для расчётов сервер создаёт скрытую платёжную запись с неизвестным случайным паролем. Она не показывается как связанный KVA-аккаунт. При последующей привязке по одноразовому коду оплаченный срок переносится на выбранный KVA-аккаунт; владелец исходного счёта сохраняется для проверки метаданных ЮKassa. Подтверждение ещё не завершённой оплаты после привязки также начисляет срок выбранному аккаунту, один раз.

После подтверждённого платежа SQLite-транзакция сохраняет срок PRO и запись синхронизации VPN. Сбой второго сервиса не теряет подтверждённую оплату: очередь повторяется каждые 15 секунд. Передаётся абсолютная дата окончания, поэтому повторная доставка не прибавляет срок дважды. VPN-клиенты создаются на обеих настроенных панелях. Пробный VPN-доступ не включает PRO.

Удаление VPN-аккаунта через приложение или веб-страницу вызывает закрытый `internal/detach`. Привязка и очередь удаляются, в `bundle_optout` сохраняется запрет автоматического восстановления VPN для KVA-пользователя. Настоящий KVA-аккаунт и PRO не удаляются; платежи после отвязки также не создают VPN заново. Только новый подтверждённый одноразовый код по инициативе пользователя отменяет запрет. Скрытая платёжная запись не даёт бесплатного доступа и сохраняется только для учёта; первичные платёжные метаданные не меняются.

Секрет связи хранится только на серверах: KVA — `/var/lib/crosshair-kva/bundle.key`, Kwyjibo — `/var/lib/kwyjibo/bundle.key`, права 600, владельцы — пользователи соответствующих служб. KVA-конфигурация `/var/lib/crosshair-kva/bundle.json` содержит фиксированный HTTPS-адрес партнёра. Секрет не включать в сайт, EXE, APK, исходники и журналы. Все межсерверные запросы проверяют TLS и секрет; redirects запрещены.

Публичный `/api/bundle/code` требует KVA Bearer-сессию. Межсерверные `/api/bundle/internal/*` требуют закрытый `x-bundle-key`. VPN-операции заказа/состояния/привязки берут VPN ID из проверенной сессии; Telegram ID берётся ботом из отправителя личного сообщения и передаётся через защищённый customer API.

Совместимость: ранее созданные DonatePay-заказы продолжают обрабатываться. У связанного аккаунта подтверждённые старые переводы синхронизируют срок PRO; выдача trial не делает этого. Автоматически созданный VPN-профиль можно перенести на свой существующий профиль через код; обычный уже связанный профиль нельзя заменить другим без разрешения поддержки. История старого служебного профиля сохраняется, его VPN-доступ отзывается.

Чеки самозанятого оформляются вручную через «Мой налог». Email собирается на этапе оплаты. Подтверждение оплаченного платежа проверяется через API ЮKassa, возврат браузера не включает подписку.

Проверки: `tests/test_bundle.py`, `tests/test_yookassa.py`; в Android-проекте — `backend/test/bundle.test.js`, тест customer bot и остальные тесты backend; release-сборка Android и unit-тесты. Инструментальная проверка интерфейса `BundleUiTest` не создаёт платежи. Проверка реального списания и работы VPN на конкретном телефоне выполняется отдельно.
