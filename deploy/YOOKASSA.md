# ЮKassa — KVA PRO

Тарифы: 100 ₽ / 30 дней, 250 ₽ / 3 календарных месяца,
500 ₽ / 6 календарных месяцев, 900 ₽ / календарный год.
Продление прибавляет период к оставшемуся сроку. Автосписаний нет.

Настройки находятся только на сервере:

- `/var/lib/crosshair-kva/yookassa.key` — секретный ключ.
- `/var/lib/crosshair-kva/yookassa-shop.json` — shopId, live/test, доступность.
- Владелец обоих файлов — crosshair; права 600.

Никогда не добавлять эти файлы в сайт, EXE, GitHub, журналы или резервные
копии, доступные через HTTP. Ключ вводится через masked getpass в
`scripts/set_yookassa_secret.py`, не через аргументы командной строки.

## Платёж

Авторизованный пользователь выбирает тариф и email для передачи чека.
Сервер задаёт сумму и владельца заказа, сохраняет код, создаёт redirect
payment с capture=true и стабильным Idempotence-Key. Возвращает только
ссылку на защищённую страницу ЮKassa и сведения о тарифе.

API `/api/subscription/order` требует provider=yookassa. Старый клиент,
с другим способом оплаты, получает 426 с предложением обновиться.
Профили, аккаунты и действующие сроки подписок сохраняются при миграции.

Сервер проверяет незавершённые платежи каждые 15 секунд и по запросу
`/api/auth/me` владельца. Можно также настроить уведомления ЮKassa:

`https://kvacrosshair.online/api/payments/yookassa`

События: payment.succeeded и payment.canceled. Без настройки уведомлений
опрос продолжает работать. Никакому статусу из тела уведомления не доверяем:
номер должен принадлежать сохранённому заказу, а состояние читается напрямую
из API ЮKassa. Проверяются магазин, live/test, paid=true, succeeded, точная
сумма RUB, metadata заказа, пользователя и тарифа. Один payment_id используется
один раз. Возврат браузера на сайт не активирует подписку.

## Чеки самозанятого

Владелец выбрал ручное формирование чеков в «Мой налог». Автоматическая
передача доходов в ФНС и отправка чеков покупателям в коде не реализованы.
Email хранится в закрытой БД и не попадает в общий каталог.
Для списка оплаченных заказов и email:

```bash
cd /opt/crosshair-kva
./venv/bin/python scripts/list_yookassa_orders.py
```

Если позднее подключается кассовая фискализация ЮKassa, нужно отдельно
настроить fiscalization_enabled и соответствующий продавцу vat_code.
Документация: https://yookassa.ru/developers/payment-acceptance/receipts/basics.

## Проверки

`python -m unittest tests.test_yookassa` — сумма, владелец, магазин, режим,
повторная активация, идемпотентность, отмена, поддельные уведомления.
`python -m tests.check_pro_ui` — локальный интерфейс и тестовая активация.
`python -m tests.check_yookassa_website` — форма и redirect с изолированным
провайдером, без реального списания. Настоящий оплаченный платёж проверяется
отдельно владельцем.
