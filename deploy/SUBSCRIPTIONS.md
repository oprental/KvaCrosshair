# KVA PRO

Оплата подписки проходит только через ЮKassa: см. [YOOKASSA.md](YOOKASSA.md).
Тарифы: 100 ₽ / 30 дней, 250 ₽ / 3 месяца, 500 ₽ / 6 месяцев, 900 ₽ / год.
Продление сохраняет оставшийся срок. Автосписаний нет.

PRO даёт цвет ника и доступ к обработке персонажей в конструкторе.
Доступ проверяется через сервер перед обработкой; сама обработка локальная.
Модель isnet-anime скачивается при первом использовании (~168 MiB),
проверяется по SHA256 и хранится в LocalAppData/CrosshairKVA/models.
Лицензия модели прилагается: assets/anime-model-LICENSE.txt.
Исходный проект: https://github.com/SkyTNT/anime-segmentation.

Контурный режим по умолчанию использует Anime2Sketch improved (MIT),
https://github.com/Mukosame/Anime2Sketch. Переведён в ONNX без обучения;
PyTorch используется только при подготовке релиза и не входит в EXE.
Модель: https://kvacrosshair.online/models/anime-lineart-v1.onnx (~183 MiB).
SHA256: 68ab9bca75cdb036f4b29117b818f5b6f337179aae30c2c371aae14891c7b78b.
Лицензия: assets/lineart-model-LICENSE.txt. Исходные improved.bin получены
из Google Drive, указанного в README автора; архитектура из его model.py.
Локальная CPU-обработка, сохранение пропорций, вход не более 1024 px,
прозрачный результат в исходном размере, сглаженные линии без бинаризации.
Регулятор порога убирает слабые детали; цвет и толщина настраиваются.
Обычный алгоритм остаётся доступным для сравнения и без второй модели.
Результат можно исправить кистью/ластиком или отменить Ctrl+Z.
