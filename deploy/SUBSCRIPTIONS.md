# KVA PRO

С версии 0.9.0 новые оплаты проходят через ЮKassa: см. [YOOKASSA.md](YOOKASSA.md).
Описание DonatePay ниже относится к прежнему способу оплаты.

Тарифы: 100 ₽ / 30 дней, 250 ₽ / 3 календарных месяца,
500 ₽ / 6 календарных месяцев, 900 ₽ / календарный год.
Продление прибавляет период к текущей дате окончания.
Автоматических списаний нет.

Ключ DonatePay хранится только на сервере:
`/var/lib/crosshair-kva/donatepay.key`, права 600, владелец crosshair.
Не переносить его в сайт, EXE, репозиторий или журналы.

Приложение создаёт заказ с уникальным кодом `KVA-…`.
Пользователь выбирает точную сумму тарифа и вставляет код в комментарий
платежа на https://donatepay.ru/don/1536419.
Сервер каждые 90 секунд читает реальные транзакции API DonatePay.
Активация требует donation/success, совпадения кода и суммы.
Номер платежа уникален: повторная проверка не продлевает подписку дважды.
Обычные добровольные донаты без кода заказа не меняют подписку.

`/api/subscription/plans` показывает доступность оплаты.
Она выключается, если API не подтверждал доступность больше пяти минут.
`payments-ready.json` не содержит ключа, только его SHA256 и время проверки.
Проверить службу: `systemctl status crosshair-catalog`.

Резервная ручная активация допускается только после независимой проверки
платежа в DonatePay:

```
cd /opt/crosshair-kva
./venv/bin/python scripts/activate_subscription.py KVA-CODE \
  --payment-id donatepay:REAL_TRANSACTION_ID --amount 100
```

PRO даёт цвет ника и доступ к обработке персонажей в конструкторе.
Доступ проверяется через сервер перед обработкой; сама обработка локальная.
Модель isnet-anime скачивается при первом использовании (~168 MiB),
проверяется по SHA256 и хранится в LocalAppData/CrosshairKVA/models.
Лицензия модели прилагается: assets/anime-model-LICENSE.txt.
Исходный проект: https://github.com/SkyTNT/anime-segmentation.

Контурный режим по умолчанию использует Anime2Sketch improved (MIT),
https://github.com/Mukosame/Anime2Sketch. Переведён в ONNX без обучения;
PyTorch используется только при подготовке релиза и не входит в EXE.
Модель: https://kvacrosshair.online/models/anime-lineart-v1.onnx (~183 MiB).
SHA256: 68ab9bca75cdb036f4b29117b818f5b6f337179aae30c2c371aae14891c7b78b.
Лицензия: assets/lineart-model-LICENSE.txt. Исходные improved.bin получены
из Google Drive, указанного в README автора; архитектура из его model.py.
Локальная CPU-обработка, сохранение пропорций, вход не более 1024 px,
прозрачный результат в исходном размере, сглаженные линии без бинаризации.
Регулятор порога убирает слабые детали; цвет и толщина настраиваются.
Обычный алгоритм остаётся доступным для сравнения и без второй модели.
Результат можно исправить кистью/ластиком или отменить Ctrl+Z.
